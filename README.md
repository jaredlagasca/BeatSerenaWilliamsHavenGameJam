# BeatSerenaWilliamsHavenGameJam
Haven game jam game
Beat Serena Williams

A web-based browser tennis game with a blackjack, coin toss, and audio.

Features

Tennis Gameplay: Court mechanics, racket physics, and an opponent (serena.png).
Coin Toss: Pre-match coin flip (coin-heads.png / coin-tails.png) to decide who serves first.
Mini-Games: Extra casino-style mini-games (casino.js).
Audio: Background music (music.m4a) and sound effects (audio.js).

Files

index.html - Main webpage layout
styles.css - Visual styling
main.js - Main initialization script
tennis.js - Tennis gameplay and physics
casino.js - Mini-game logic
audio.js - Audio and sound controller
design.md - Project design notes
*.png & music.m4a - Game graphics and audio assets

How to Run

Download or clone this repository.
Open the Tennis 2 folder.
Double-click index.html to play the game in your web browser.
